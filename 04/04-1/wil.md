HTTP 프로토콜 : 클라이언트와 서버 간 미리 약속한 규칙

HTTP 요청 : 클라이언트에 서버로 자료 요청
HTTP 응답 : 서버에 클라이언트로 자료 전달

네트워크 창에 나타난 필요한 파일들 내 존재하는 정보들
내려받은 파일 하나 클릭시,
- 요청 헤더 : 시스템 정보, 웹 브라우저 정보, 사용한 언어 등 다른 정보가 포함
- 요청 본문 : 요청한 내용 그 자체

- 응답 헤더 : 현재 파일이 어떤 형식을 사용하는지 인코딩
- 응답 본문 : 브라우저 창에 보여 줄 텍스트나 이미지 같은 사이트 내용이 들어감

헤더
1. 일반 헤더
- 요청 URL : 어떤 정보를 보내 달라고 요구하는 URL
- 요청 메서드 : 클라이언트에서 서버로 보내면서 그 정보를 어떻게 처리할지를 설명
GET 메서드 : 서버에서 정보를 가져올 때 사용
POST 메서드 : 서버에 데이터를 저장할 때 사용
PUT 메서드 : 서버에 있는 데이터를 수정할 때 사용
DELETE 메서드 : 서버에서 데이터를 삭제할 때 사용
- 상태 코드 : 보낸 요청 성공 여부 알려주는 3자리 코드
주요 코드
- 1xx : Informational, 계속 처리 중
- 2xx : Successful, 요청 성공
  1) 200 : OK, 성공적으로 처리
  2) 200 : Created, 성공적으로 처리, 새로운 자료 생성
  3) 200 : No Content, 성공적으로 처리, 응답으로 반환할 내용 없음
- 3xx : Redirection, 다른 위치로 이동
  1) 301 : Moved Permanently, 요청한 데이터가 새 URL로 옮겨졌습니다.
- 4xx : Client Error, 클라이언트 오류
  1) 400 : Bad Request, 클라이언트 요청 오류 혹은 유효하지 않음
  2) 401 : Unauthorized, 권한이 없어 거절되었지만, 인증 다시 시도 가능
  3) 403 : Forbidden, 권한이 없어 거절되었고, 인증 시도해도 계속 거절
  4) 404 : Not Found, 해당 데이터 찾기 불가능
- 5xx : Server Error, 서버 오류
  1) 500 : Internal Server Error, 서버에 요청을 처리하는 동안 오류 발생
  2) 503 : Service Unavailable, 요청한 서비스 이용 불가능

원격 주소 : IP 주소와 포트 표시
IP 주소 : 인터넷 프로토콜 주소
포트 : 콜론(:)기호를 이용해 작성, 어떤 프로그램을 어디에 실행할지를 지정
주요 번호 : 
- 20, 21 : FTP
- 25 : SMTP
- 53 : DNS 서버
- 80 : 웹(HTTP)
- 110 : POP3(이메일 수신)
- 443 : HTTPS
