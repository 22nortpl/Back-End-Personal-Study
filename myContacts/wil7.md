미들웨어 : 익스프레스의 도우미, 요청과 응답 중간에 있으면서 요청을 처리하거나 원하는 형태로 응답을 수정하는 함수

예시
- 로그인 처리하는 과정
1) 요청 안에 포함된 아이디와 비번 값을 애플리케이션에서 읽을 수 있는 형태로 변환
2) 아이디와 비번 값을 사용해서 사용자 인증
3) 처리 결과를 다음 단계로

역할 : 요청과 응답 주고받을 때 많은 처리를 담당
- 요청 전처리 : 요청이 서버에 도착하기 전 실행하는 작업 담당 ex : 사용자 인증, 폼 내용 검증

- 라우팅 처리 : 지금까지 특정 URL로 들어온 요청을 미리 만들어 둔 함수

- 응답 처리 : 서버에서 클라이언트로 응답을 보낼 때 자료를 적절한 형태로 변환하거나 오류를 처리하는 작업

애플리케이션 레벨 미들웨어
const app = express();

app.get("/contacts", (req, res) => {...});
에서 (req, res) => {...}가 미들웨어

라우터 미들웨어
const router = express.Router();
라우터 그 자체를 미들웨어로 취급

app.use 함수 : 미들웨어 등록

바디파서 미들웨어 : 서버로 요청을 보낼 때 요청 본문에 담긴 것을 파싱하는 미들웨어
파싱 : 요청할 때 전송된 자료를 프로그램에서 사용할 수 있는 형식으로 변환

바디파서 : 외부에서 그 내용을 볼 수 없도록 파싱해서 객체에 할당할 때 사용

함수
- .json : JSON 형식의 본문을 파싱
- .urlencoded : URL로 인코딩된 본문을 파싱
- .raw : 가공되지 않은 바이너리 자료를 파싱
- .text : 텍스트 형식의 본문을 파싱

미들웨어는 순서가 중요
