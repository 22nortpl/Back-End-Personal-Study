익스프레스 : 프레임워크 중 하나
HTTP 모듈 내에서 다루는 함수 외에 다양한 함수를 만히 다룸

기능
라우팅 : 원래 if, switch문으로 라우팅하는 방법을 더욱 간단하게
미들웨어 : 요청과 응답 사이에서 여러 가지 기능 실행 가능, 자주 사용하는 미들웨어는 가져와서 사용
템플릿 엔진 : 동적인 HTML 페이지 구성, 보이는 뷰를 담당
정적인 파일 지원: 익스프레스에서 동적인 파일만 생성하는 것이 아닌 CSS, JS, 이미지 등의 기능도 제공

nodemon : 서버 코드를 수정하면서 결과 확인하는 과정을 직접 종료하지 않고도 브라우저만 새로고침 시 변경 사항 적용하게 함
