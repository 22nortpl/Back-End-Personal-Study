파일 읽기 : fs.readFileSync(경로, {옵션});
옵션
- encoding (위쪽 내용과 동일하나, 기본값이 null)
- flag : 파일 읽을 때 어떤 형태일지 저장 (기본값은 r)
비동기 처리 : readFile 함수
fs.readFile(경로, { 옵션 }, 콜백);
옵션 
- encoding (위쪽 내용과 동일)
- flag : 파일 읽을 때 어떤 형태일지 저장 (기본값은 r)
- signal : 파일 읽는 데 시간 걸리면 signal 옵션으로 중간에 파일 읽기 취소
매개변수는 err, data

파일 기록하기 : fs.writeFileSync(파일, 내용, {옵션});
옵션
- encoding (위쪽 내용과 동일하나, 기본값이 utf8)
- flag : 기본값 w
- mode : 파일에 사용자의 권한을 설정, 기본값은 0o666
비동기 처리 : writeFile 함수
fs.readFile(파일, 내용, { 옵션 }, 콜백);
옵션 
- encoding (위쪽 내용과 동일하나, 기본값이 utf8)
- flag : 기본값 w, 기존 파일에 내용 추가시 a 사용
- mode : 파일에 사용자의 권한을 설정, 기본값은 0o666 
매개변수는 err, data
기존 파일에 내용 추가 : flag 옵션 사용
"a" : 내용 추가 위해 파일 열기, 없으면 만들기
"ax" : 위와 같지만 파일이 있으면 실패
"a+" : 파일을 읽고 내용을 추가하기 위해 파일 열기, 없으면 만들기
"ax+" : 위와 같지만 파일이 있으면 실패
"as" : 동기 처리로 내용을 추가하기 위해 파일을 열기
"w" : 작성을 위해 파일 열기, 없으면 만들기
"wx" : 위와 같지만 파일이 있으면 실패
"w+" : 내용을 읽고 작성을 위해 파일 열기, 없으면 만들기
"wx+" : 위와 같지만 파일이 있으면 실패

파일 기록하기 : fs.existsSync(파일);

기존 파일에 내용 추가하기 : fs.appendFileSync(파일, 내용, {옵션});
옵션 
- encoding (위쪽 내용과 동일하나, 기본값이 utf8)
- flag : 기본값 w, 기존 파일에 내용 추가시 a 사용
- mode : 파일에 사용자의 권한을 설정, 기본값은 0o666 
비동기 : fs.appendFile(파일, 내용, {옵션}, 콜백);

파일 삭제하기 : fs.unlinkSync(파일);
비동기 : fs.unlink(파일, 콜백);
