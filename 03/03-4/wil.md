디렉터리 만들기 : fs.mkdirSync(경로, {옵션});
옵션 
- recursive : 기본값 false, 여러 계층의 디렉터리를 지정했을 때 중간에 존재하지 않는 경로까지 포함 가능
- mode : : 디렉터리의 권한 지정, 기본값은 0o777
비동기 : fs.mkdir(경로, {옵션}, 콜백);
콜백 형태 매개변수 : err
여러 계층 생성은 폴더 사이에 / 추가

빈 디렉터리 삭제 : fs.rmdirSync(경로, 내용, {옵션});
옵션
- maxRetries : 기본은 0, 오류가 발생해서 디렉터리를 삭제하지 못했을 때 재시도할 횟수 지정
- retryDelay : 기본은 100, 재시도 횟수를 지정할 경우 대기 시간 지정 가능
비동기 : fs.rmdir(경로, {옵션}, 콜백);
콜백 형태 매개변수 : err

파일 삭제 및 내용이 있는 디렉터리 삭제 : fs.rmSync(경로, 내용, {옵션});
옵션 
- force : 기본은 false, true로 지정 시 파일이나 디렉터리를 강제로 삭제
- maxRetries : 기본은 0, 오류가 발생해서 디렉터리를 삭제하지 못했을 때 재시도할 횟수 지정
- retryDelay : 기본은 100, 재시도 횟수를 지정할 경우 대기 시간 지정 가능
- recursive : 기본값 false, 경로가 여러 단계라면 단계별로 삭제 작업 실행
비동기 : fs.rm(경로, {옵션}, 콜백);
콜백 형태 매개변수 : err
