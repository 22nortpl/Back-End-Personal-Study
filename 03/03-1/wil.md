path 모듈이 필요한 이유 
1. 경로 구분자를 통일 가능
windows는 \를, Mac이나 Linux에서는 /를 사용

2. 경로를 나누거나 통합 가능
파일 확장자 등 정보 포함

경로 표현 방법
절대 경로 : 루트 root 폴더부터 시작해서 파일까지 전부 표현

상대 경로 : 기준이 되는 파일이 있을 경우 사용하는 표현
하위 폴더에 있으면 /
같은 폴더에 있으면 ./
상위 폴더에 있으면 ../

경로 다루는 주요 함수

path 모듈 가져오기 : require("path");

__filename : 절대경로
path.dirname(경로) : 경로만 추출

basename 함수 : 파일 이름만 추출, 확장자도 빼고 싶으면 확장자도 괄호에 추가

extname 함수 : 확장자만 추출
